RallyMotionReasoner

Motion-aware event grounding and tactical reasoning for tennis videos.

Repository Algorithm notes

Pipeline

Video and ball trajectories are converted into hit and bounce events, organized as a tactical graph, and routed as evidence for downstream reasoning.

Trajectory + video→Region-motion events→RGR graph reasoning→Grounded answer

Event model

The current runtime averages independently checkpointed TrajectoryExpert and VisualExpert scores. A joint cross-attention model is defined but is not used by the checkpointed runtime.

Graph reasoning

Hit nodes, bounce cues, temporal relations, motion statistics, and 800-dimensional frame descriptors are consumed by RGR.

Evidence

Question-conditioned routing selects supporting strokes and key actions before optional Qwen generation.

Repository status

The repository provides model structure, runtime integration, training entry points, and lightweight contract tests. External weights and broadcast videos are not included. No reproduced numerical result is claimed.
