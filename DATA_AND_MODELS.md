# Data and model release policy

## Current status

TRACE annotations, pretrained TennisVAR checkpoints, LoRA adapters, and cached visual features are not included in this repository. The release process is still under review.

## Tennis footage

Professional tennis broadcasts may be controlled by tournament organizers, broadcasters, platforms, or other rights holders. The TennisVAR code license does not grant permission to download, redistribute, or use that footage.

We are evaluating release options that preserve research utility without redistributing protected media. These may include annotation-only metadata, stable references, integrity manifests, and preparation scripts for users who already have lawful access to the corresponding videos. No specific release format or date is promised yet.

## Checkpoints

EPM, TGTR, and Qwen3-VL LoRA weights will be considered for a separate release after their training provenance, upstream licenses, and artifact contents have been audited. External DINOv3, TrackNet, and Qwen3-VL assets remain subject to their own licenses and terms.

## Requests

Please do not open issues requesting private copies of match videos or unpublished annotations. Public release updates will be recorded in the repository README and project page.
